# Games

## Overview

Games is a collection of small game projects. At present, the repository contains **Snake V1**, a terminal-based C++ game in [`snake_v1`](snake_v1/README.md). The root folder is intended to hold additional small games as they are added.

## Current Projects

- [Snake V1](snake_v1/README.md) - a Windows console Snake game written in C++.

## Tech Stack

The collection does not have a shared technology stack. The current Snake project uses C++ and Windows console APIs; see its README for prerequisites and build instructions.

## Prerequisites and Running

Prerequisites and run commands depend on the individual game. For the currently included project, use the Windows and MinGW `g++` instructions in the [Snake V1 README](snake_v1/README.md).

## Tests

No collection-wide test runner or automated test suite is configured. Check each game's README for project-specific testing details. Snake V1 currently has no automated tests.
